# Checklist de lançamento - Orbyta

## 1. Técnico
- [ ] Definir `SECRET_KEY` forte no `.env`
- [ ] Rodar com `python serve.py`
- [ ] Validar login admin, dono, funcionário e cliente
- [ ] Testar criação de negócio, serviço e agendamento
- [ ] Gerar backup com `python backup_data.py`
- [ ] Configurar HTTPS no ambiente de hospedagem

## 2. Comercial
- [ ] Definir preço mensal e período de teste
- [ ] Criar página simples de apresentação
- [ ] Preparar mensagem de onboarding para novos clientes
- [ ] Definir canal de suporte (WhatsApp/Email)

## 3. Jurídico
- [ ] Termos de uso
- [ ] Política de privacidade
- [ ] Adequação básica à LGPD

## 4. Go-live
- [ ] Publicar servidor
- [ ] Criar 1 conta real de demonstração
- [ ] Testar cobrança/assinatura
- [ ] Fazer primeiro backup pós-publicação
